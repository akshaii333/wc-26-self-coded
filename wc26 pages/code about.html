ABOUT WC-26

WC-26 is an experimental football tactical intelligence dashboard exploring how immersive sports analytics interfaces can support match analysis, tactical exploration, and customizable data interaction. Inspired by professional scouting systems and Meridian’s overview-detail interface framework, the project combines semantic zooming, adaptive data layers, synchronized views, and tactical visualizations into a cohesive football intelligence experience.

The platform was designed as a speculative sports analysis system where users can navigate between match archives, live tactical breakdowns, performance analytics, and customizable dashboard views without disrupting the overall analytical workflow. Rather than functioning as a traditional sports website, WC-26 explores how dense football data, interactive overlays, and contextual interface controls can create a more immersive and flexible tactical analysis environment.
